# Homepage of fx.cpphusky.xyz

This is a simple homepage for https://fx.cpphusky.xyz.

It provides the user a selection card, to choose the currency they want (TGT), and the currency they use (SRC), generate a link `https://fx.cpphusky.xyz/${TGT}-${SRC}` for the user to visit, so that the user can directly subscribe to this channel.

It should provide a tutorial too, refering [this README](https://github.com/cppHusky/fx-logger#from-my-ntfy-server). The user may use Desktop App, Desktop Browser, Android App, Android Browser, iOS App or iOS browser. for different choice provide different tutorial.
